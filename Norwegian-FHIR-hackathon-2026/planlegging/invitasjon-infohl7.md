# Velkommen til Norsk FHIR Hackathon 2026

HL7 Norge inviterer til Norsk FHIR Hackathon i forbindelse med EHiN den 9. november 2026.

Bli med for å lære om og utforske nye løsninger for interoperabilitet sammen med leverandører og helsevirksomheter i Norge. Delta i diskusjoner, test ideer og implementasjon og del erfaringer om hvordan vi kan koble helsetjenesten bedre sammen med åpne standarder. Hackathon arrangerers sammen med NHN, NAV, Helsedirektoratet, Bedredelt, DMP og IHE Norge og gir deltakerne mulighet til å lære mer om FHIR Restful API og bruk av FHIR for integrasjon av systemer og dokumentasjon av grensesnitt. FHIR Hackathon er en del av EHiN prekonferanse 2026.


Dato: 09. november 2026  
Tid: 0900-1700  
Sted: EHiN prekonferanse på Rebel i Oslo
Pris: gratis (inkluderer lunch, deltakere dekker reise og eventuelt opphold selv)  
Påmelding: Påmeldingskjema  
Detaljert informasjon: Norsk FHIR Hackathon 2026  

Det arrangeres et formøte på video den 2. november 2026 klokken 09:00-11:00 hvor det gis informasjon om arbeidssporene og muligheter for spørsmål og dialog om oppgavene og forberedelser.

## Innhold

Hovedmålet med det Norske FHIR Hackathon er å bygge FHIR kompetanse i Norge og Norden ved å implementere og teste faktiske FHIR RESTful API tjenester og programvare.
Under FHIR Hackathon kan du:

Implementere og teste FHIR API for Pasientens planer med NHN
Teste bruk av SMART on FHIR med NAV
Lære om bruk av FHIR medication med DMP
Lære å bruke IHE MHD med IHE Norge
Lære om EHDS Patient Summary med IHE Norge og Helsedirektoratet
Skrive og publisere dokumentasjon for FHIR API med IG publisher

Det er begrenset antall plasser, meld deg på i dag på via påmeldingsskjemaet.
