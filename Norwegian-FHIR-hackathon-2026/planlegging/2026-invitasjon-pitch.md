# Pitch

## Inspirasjon

* Utforsk og samskap fremtidens samhandlingsløsninger med HL7 FHIR – Bli med på en gratis, inspirerende hackathon  
* Deltakerne mulighet til å lære mer om FHIR Restful API og bruk av FHIR for integrasjon av systemer og dokumentasjon av grensesnitt.  
* Everyone curious about health data hacking is invited, for learning, networking and hacking.

## Forslag

Health data hacking på Norsk. På det Norske FHIR Hackathon lærer vi hvordan standardisert samhandling kan fungere i praksis. Årets event tar for seg alt fra samhandling i europa via utvikling av SMART apper til integrasjon av informasjon fra flere informasjonstjenester.

Vi skal jobbe med fem forskjellige tracks på årets Hackathon:

1. NHN FHIR services track - Måledata og behandlingsplaner
2. SMART on FHIR - SMART apper i NAV
3. Document sharing for IHE MHD - IHE og FHIR
4. EHDS track - FHIR i europa
5. FHIR 101 - FHIR for beginners
