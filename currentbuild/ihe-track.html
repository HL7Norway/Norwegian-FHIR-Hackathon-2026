Ihe Track

API Access and Document Sharing in Norwegian and European context

In this track we will work on the technical parts of API Access and document sharing within Norwegian and European context. We will work on the technical API and not on content profiles. The content will be explored in EHDS Track.

EU Health Data API

The IHE/HL7 Health Data API Implementation Guide is build to be harmonized with expected requirements in EHDS for the technical part of data sharing.

The profile is buld on recognized and proven exchange patterns from international IHE Profiles and HL7 implementation guides:

  • ​Capability Discovery - Discover which priority categories a server supports
  • ​Authorization - SMART Backend Services (IUA actor model)
  • ​Patient Matching - PDQm Patient Demographics Query
  • ​Document Exchange - MHD transactions (ITI-67, ITI-68, ITI-105)
  • ​Resource Access - International Patient Access (IPA) resource query patterns
NHN Dokumentlager

NHN Dokumentlager is an implementation of the European Health Data API and can be used for health care providers in Norway to share documents. Currently norwegian municipalities and avtalespesialister are working towards using this infrastructure for document sharing. NHN will provide versions of the NHN Dokumentlager for practical connectivity testing. There will be alternatives with and without authorization.
