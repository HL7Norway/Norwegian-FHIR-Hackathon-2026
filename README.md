# FHIR Hackathon 2026

Date: November 9, 2026  
Location: Rebel  
[Information and agenda](https://hl7norway.github.io/Norwegian-FHIR-hackathon-2026/currentbuild/)  

## Organization

The Norwegian FHIR Hackathon 2026 takes place at Rebel in Oslo on November 9, 2026. The Norwegian FHIR hackathon is hosted by [HL7 Norge](https://www.hl7.no/) in cooperation with [NHN](https://www.nhn.no/), [Helsedirektoratet](https://www.helsedirektoratet.no/), [Bedredelt](https://bedredelt.no/), [NoMA](https://www.dmp.no/en/), IHE Norge and [EHiN](https://ehin.no/).

## About this repo

This repo is used for planning, information and documentation of results from the Norwegian FHIR Hackathon 2026. All participants on the Hackathon are encuraged to document results as separate pages in the resulting Implementation Guide.
